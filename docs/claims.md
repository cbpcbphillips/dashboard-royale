# Claims & Evidence

Every number that appears in the dashboard, write-up or video must have a row here. Each verified claim points to a re-runnable query (`sql/claims/Cxx.sql`, D-011). Re-check any claim with `uv run python -m royale.claims C01` (add `--engine databricks` to run it on Databricks) so it can be re-checked before submission.

Columns: **ID · Claim · Query · Result · Alternative explanation tested · Limitation · Used in**

Conventions applied to every query: ratio of sums; active rows only (`active AND location_id IS NOT NULL`); `_cents` ÷ 100; hours from `scheduled_seconds`; theo vs actual kept separate; timestamps converted to gaming date (06:00–06:00 local).
